Your task
Build a new Flutter project with one screen that allows the user to:
1. Enter an expense name, such as Food, Transport, or Internet.
2. Enter an expense amount.
3. Press an Add button to add the expense.
4. See the expenses they've added.
5. See the total amount spent, which updates whenever an expense is added.
6. Prevent empty expense names and invalid amounts from being added.
Rules
- Use StatefulWidget and setState().
- Use TextField and TextEditingController for input.
- Use a List to store expenses.
- Use the Flutter widgets and Dart concepts you've learned so far.
- No database, APIs, packages, or advanced state management.
- You decide the layout, colors, typography, spacing, and overall design. I won't give you a visual blueprint.
