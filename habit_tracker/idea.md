equirements
1. The user can enter a habit name, such as “Read 10 pages.”
2. An Add Habit button adds the habit to a list.
3. Each habit appears with a button that lets the user mark it as completed.
4. Show the total number of habits and how many are completed.
5. The user must not be able to add an empty habit.
6. Completing a habit should update the screen immediately.
Rules
- Use StatefulWidget, setState(), TextEditingController, and a List.
- Use only Flutter widgets and Dart concepts you've already learned.
- No database, APIs, packages, or advanced state management.
- Choose your own colors, layout, typography, and spacing.
- Start with a blank file. Don't copy your Expense Tracker code.
